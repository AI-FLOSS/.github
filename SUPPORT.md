# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/orgs/x-tech-laboratories/discussions) or
  Matrix in [#x-tech-laboratories-general](https://matrix.to/#/#x-tech-laboratories-general:matrix.org).
- **Bugs and feature requests:** open an issue in the project's repository.
- **Security problems:** see the [security policy](SECURITY.md); never post them publicly.
