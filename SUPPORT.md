# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/orgs/AI-FLOSS/discussions) or
  Matrix in [#ai-floss-general](https://matrix.to/#/#ai-floss-general:matrix.org).
- **Bugs and feature requests:** open an issue in the project's repository.
- **Security problems:** see the [security policy](SECURITY.md); never post them publicly.
