# AI policy

AI-FLOSS projects welcome contributions made with AI tools. This policy applies to every repository
in the organisation unless a repository has its own `AI_POLICY.md`.

## You are accountable

Whoever opens a pull request owns it, however it was written. Before you submit:

- Read and understand every line you are proposing. You must be able to explain and defend it in review.
- Run the project's tests and make sure they pass.
- Follow the project's `AGENTS.md`, if it has one, and point your agent at it.

## Disclose

Say how AI was involved, using the checkbox in the pull request template. Disclosure is expected and
is never held against a contribution. For individual commits, an `Assisted-by:` trailer naming the
tool is welcome; see the [disclosure guideline](https://ai-floss.github.io/guidelines/disclosure/).

## Respect people's time

- Keep pull requests focused. Large, unrequested rewrites are likely to be closed.
- Do not open issues or pull requests generated in bulk, or reply to review with unread AI output.
- Maintainers may close contributions that show no sign of human review.

## Licences

AI-assisted work follows the same rules as any other: you must have the right to submit it under the
project's licence, and you must not paste in code whose licence is incompatible.
